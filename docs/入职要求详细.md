## 岗位定位

负责机器人云端运维体系、教育平台及 Web 管理后台的全栈开发，构建“题库管理 + AI 机器人互动 + 设备运维”三位一体的教育机器人云平台。

## 岗位职责

### 1. 教育平台开发（核心）

- 设计并开发教育场景下的题库管理系统。
- 实现 AI 机器人互动教学功能。

### 2. Web 管理后台全栈开发

- 负责机器人远程运维管理后台的前端与后端开发。
- 实现机器人设备管理、状态监控和日志查询。
- 实现远程指令下发与 OTA 升级。

## 任职要求

- 计算机、软件工程、教育技术等相关专业，本科及以上学历。
- 熟悉 Python、FastAPI，以及 RESTful API 的设计与开发。
- 熟悉 MySQL、PostgreSQL 等数据库系统，具备表分区及性能调优能力。
- 熟悉 Vue、TypeScript/TSX 等前端开发技术。
- 熟悉 MQTT、HTTP、WebSocket 协议。
- 具有物联网或机器人设备接入经验者优先。

## 加分项

- 具有教育类产品开发经验，例如在线教育、题库系统或学习管理系统。
- 具有机器人或智能硬件云端平台开发经验。
